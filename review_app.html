The queue jumps to unreadable characters first, then conflicting readings, then weaker warnings. Click any other character to edit it; the next step returns to the uncertain queue. Unflagged text can still be wrong. The orange image marker is an approximate position; inspect nearby letters too.

Check field boundaries

Character corrections cannot fix a name assigned to the wrong column. Inspect the record's page and correct any field here. Saved field corrections take precedence over later character edits until reset. Refresh fields after character edits; save your field edits before refreshing.

What the workbook contains

Converted records follows ID + fields 1–36. Missing field boundaries appear as [?]. Text regions retains every detected line, including fragments that could not be mapped. Review status lists character and layout issues. Corrections save automatically.

Reviewing every flagged character does not validate every field boundary. This development version does not certify 100% accuracy or label a workbook “fully verified”.
